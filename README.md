Python and Jupyter coursework completed as part of my bioinformatics studies. This collection explores how classical machine learning algorithms work, how preprocessing changes their behavior, and how to evaluate classification and clustering results.

## Tools and data

Python, NumPy, pandas, SciPy, scikit-learn, Matplotlib, and Jupyter. The exercises reference cancer-classification, spam-classification, synthetic clustering, and route-optimization datasets.

## Reading and reproducing the work

Start with the linked scripts or rendered notebooks. Several algorithms are implemented directly to study their mechanics; other exercises use scikit-learn. The original CSV datasets are not included in this repository, and scripts contain local paths that must be updated. There is no pinned environment or unified runner. These historical learning exercises have not been revalidated against current dependencies; no benchmark or clinical-performance claim is made.
